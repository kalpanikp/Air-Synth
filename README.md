# Air Synth

Play beats and synths live with your hands. It runs in the browser and works on laptops and phones.

**Live:** https://kalpanikp.github.io/Air-Synth/

## Gestures
**Left hand: beats**
- 1–5 fingers set the drum layers (kick → clap → hats → percussion → full)
- Fist drops the beat. Open your hand and it slams back on the next bar
- Pinch and move up/down to sweep a filter over the drums

**Right hand: instrument** (pinch thumb + index to play)
- Left ↔ right picks the note or chord, locked to the key. Up ↕ down sets the filter
- Spread your other fingers to add reverb and delay
- Modes: Lead, Bass (acid), Arp, Chords (Pad/Keys/Supersaw/Pluck), Theremin, FX (DJ filter + delay throw)

**Both hands:** pinch and hold to start a riser. Pull apart to build it, let go for an impact on the next bar.

## Features
- Scenes: Intro, Groove, Build (4-bar roll + riser + auto-drop), Drop, Break
- Kits: House, Techno, Trap, Dhol
- Scales include Bhairav and Dorian (Kafi)
- 4-bar note looper with overdub
- Recording to .webm
- Calibration for your reach
- Every gesture is quantized to 1/16

## Phone use
- Open the link in Chrome (Android) or Safari (iPhone). It needs https, so a downloaded file won't get the camera.
- Put the phone on a stand in landscape, 60–80 cm away, so both hands are free.
- On iPhone, turn the silent switch off.
- Use a Bluetooth or aux speaker. The phone speaker loses the bass.
- To get a fullscreen app icon: Add to Home Screen.
- After the first online load, it keeps working offline.

## Keyboard
`1–6` modes · `Z X C V B` scenes · `L` loop · `K` clear loop · `R` record · `Space` play/pause · `P` panic · `F` fullscreen · `H` help

Built with MediaPipe Hands and Tone.js. The camera feed never leaves your device.
